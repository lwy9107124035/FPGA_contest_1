时钟＝大屏右上角显示当前时间；频谱＝底部随声音跳动的柱条；缩放＝卡里任意分辨率的图（如 1280×720、400×800）自动等比缩放到屏幕中央（恒定铺满 640×480 帧缓冲，黑边居中，不会花屏；b-19 起"极扁条带"也走缩放，不再特殊直通）。点一下切开关（发 CK/VU/SC 0/1）；SC 开了以后按一次「下一张」才生效（缩放发生在换图时刻）；若卡里有非 640×480 的图（多分辨率演示卡），必须先开缩放、再点【扫满 32 张】——登记发生在扫描那一刻，顺序反了非标准图进不了候选表（重扫一次即恢复）。按钮记的是网页最后一次点击，板子断电重启后回到默认。
