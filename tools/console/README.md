# 📺 FPGA 播控终端 · 图形控制页（console）

**这是什么**：替代 XCOM 的上位机网页。不用记命令、不用敲键盘——
大屏按钮点一下就见效；SD 卡里的图片以缩略图墙的形式摆在你面前，
勾几张就只播几张；手机照片拖进来自动转成板卡能播的 BMP。

---

## 三步启动（小白版）

1. **插线、上电**：USB-TTL 连好板子（驱动装过、知道是 COM4）。
   不想接板子先玩界面？跳过这步，用第 2 步的 `--mock`。
2. **双击启动**（或在 cmd 里输入这一整行）：
   ```
   C:\Users\lwy\miniconda3\envs\fpga_batch\python.exe C:\td_batch\lab_pro\tools\console\console.py
   ```
   演示/无板模式在后面加空格再写 `--mock`（**绝对不碰串口**）。
3. **浏览器自动弹出** `http://127.0.0.1:8765`。没弹出来就手动输这个网址。

> ⚠️ 开跑前先把 XCOM / 串口监视器关掉：COM4 同一时刻只能一个程序用。
> 忘了关也不怕——页面会变灰并给你「⟳ 重连」按钮，关掉占用者点重连即可。

## 页面上都有什么

| 区域 | 干什么 | 背后发的命令 |
|---|---|---|
| 顶部状态条 | 每 0.5 秒自动问一次板子：扫描/轮播/图号/屏有效/忙/命令计数 | `INFO?`（查询不计数） |
| 🎮 大屏快捷操作 | 下一张、轮播开关、应急1·2·3、恢复常态、全部播放、快扫7张 | `NEXT AUTO EMG1-3 CLR PLYALL SCAN7/4` |
| 📢 文字广播 | 大字输入＋“已用 X/22 格”实时计数＋八色色块＋音量滑条 | `COL n` → `MSG …`（GB2312）、`VOL n` |
| ⏱ 轮播节奏 | 全局每张秒数；给第 1~7 张各配一个秒数 | `SPD n`、`T 0-6 n` |
| 🖼 资源墙 | 自动发现 TF 卡根目录 `BMP*.BMP`（没卡→sd_prep\bmp_out→console\bmp_out），每张图一个缩略图卡片；勾选即选播子集，掩码自动换算 | `PLY <掩码>`（3张→`PLY 07`，7张→`PLY 7F`） |
| 🧳 导入工坊 | 多选 jpg/png/gif/bmp/webp/视频 → 640×480 24bit 板卡 BMP；检测到 TF 卡时给「一键拷进卡」（覆盖前弹窗确认） | 本地转换，不发串口 |
| 🧾 回执流 | 每条“发令 → 板子回执”，ERR 红色；查询刷屏已静音 | — |
| 🔧 高级抽屉 | 右上「高级」：原文收发框 + `STAT?` 十六进制视图（给极客，保留 XCOM 能力） | 原样发送 |

## 已知限制（说人话）

- **视频抽帧需要本机 ffmpeg**：本机 PATH 里没检测到 —— 没有它时页面自动禁用视频转换并写明原因，图片转换不受影响。
- **TF 卡在 PC 与在板上互斥**：卡插在电脑读卡器上，板子就读不到卡；拷完图要把卡放回板上再按 `SCAN7`。
- **图号只有 2 位**：`INFO?` 协议里图号字段只占 2 bit（0..3 循环），7 张图时状态条显示“第 N 张·低2位”，不是 bug。
- **PLY 掩码歧义区**：100~105 和 112~121 这 20 个子集组合，其十六进制写法全是数字，板子 v9.1 会按十进制误读 —— 协议上无法精确表达，页面勾选到这类组合会直接弹提示让你调整（常用组合不受影响；`PLYALL` 永远能全放）。
- **本工具不发送固件更新**：`LOAD`（字库烧写）仍走 cjk_flash 原工具，页面不碰它。

## 文件一览

```
console/
├─ console.py      主程序：HTTP 服务(8765) + /api 动作分发 + 命令队列接入
├─ fpga_link.py    协议层：命令编码 / FakeSerial 假板子 / SerialLink 串行队列
├─ assets.py       素材层：TF卡发现(ctypes) / Pillow 缩略图缓存 / make_bmp 函数复用
├─ ui/index.html   页面（内联 CSS/JS，零外部资源，断网可用）
├─ selftest.py     79 项验收测试（--mock，零串口风险）
├─ thumbs/         缩略图缓存（自动创建，可随手删）
└─ bmp_out/        导入工坊的转换输出目录（自动创建）
```

只写自己目录：`thumbs/`、`bmp_out/`；`sd_prep/make_bmp.py` 只借用函数、绝不修改；
往 TF 卡根目录拷 BMP 只在用户按「一键拷进卡」并在弹窗里确认后进行。
